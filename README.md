# GameplayMod

Механики мира для Смешариков: персонажи (вселение, одежда, способности), тарзанки и верёвки, плоты и бревно, воздушный шар и ветер, лава, обстрелы, жерла, дым, скаты и мост механик для уровней.

Часть набора модов «Смешарики» для Minecraft 26.2 (Fabric, Java 25). Общее описание, установка и состав набора — в [корневом README](https://github.com/NoPasaRun/smeshariki-demo#readme).

Игрок вселяется в смешарика (в выживании выбирает персонажа при входе), дальше у каждого персонажа свои способности. Механики настраиваются маркерами в мире, а уровни управляют ими через мост механик (`api/Mechanics`).

## Клавиши

| Клавиша | Действие |
|---|---|
| Ctrl, Shift, ПКМ, ЛКМ с маркером в руке | настройка жерла и других маркеров (курс, дальность, высота, шаг) |
| `]` / `[` | удлинить / укоротить верёвку |
| Tab | ось руля шара (стропа руля в руках) |

## Сборка

```
./gradlew jar --no-daemon -Dorg.gradle.jvmargs=-Xmx900m
```

Результат — `build/libs/gameplaymod-1.0.0.jar`. Моды компилируются против соседних jar в `../<Мод>/build/libs/`, порядок сборки: SmesharikiMod → GameplayMod → WorldMod → BehaviorMod, BuildMod → LevelMod.
